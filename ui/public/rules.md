# 四川麻将血战到底规则

本文规定本项目采用的四川麻将血战到底玩法，包括行牌流程、番型倍数和结算方式。更新日期：2026-10-20。

**计分状态：按2026-10-20用户补充，独立加倍与牌型倍数相乘，最终封顶512倍。明确排除：七对类与九莲宝灯不计门前清；龙七对类（含双龙、三龙及清、将组合）与十八罗汉类不额外计根；连七对不计断幺九。其他合法暗手中的四张相同牌算根，杠出的牌不计根。以本文最新的明确排除项为准。**

## 一、牌张与人数

- 4人参与，使用万、条、筒三门，共108张。
- 每门从1至9，每种牌各4张，共36张。
- 不使用风牌、箭牌和花牌。
- 允许碰、杠、胡，不允许吃牌。

## 二、庄家、发牌与换三张

### 庄家

首局由系统随机确定，实体牌局可通过掷骰确定。后续按百科“游戏术语”的版本，由上一局最先胡牌者坐庄；若首次胡牌事件为一炮多响，则由点炮者坐庄。流局后的坐庄方式暂待确认，不与条目另列的“血战每局投骰”版本混用。

### 发牌与行动方向

本项目沿用原定的逆时针玩家轮转。玩家摸打的顺序与牌墙取牌方向分别记录，不再表述为“玩家顺时针摸牌、逆时针出牌”。

1. 实体牌局由庄家掷两枚骰子确定开牌位置；系统牌局记录洗牌结果及起始位置。
2. 从庄家开始，四家每轮依次各取4张，重复3轮，每家得到12张。
3. 各家再补足手牌：庄家14张、其他三家各13张。
4. 完成换三张和定缺后，由庄家先打出一张牌。

### 换三张

发完手牌后，每位玩家选择3张同花色的牌，随机与其他1位玩家交换。

四家全部提交后，由系统统一确定顺时针、逆时针或对家交换，交换完成后再定缺。随机方向的具体生成方式待明确。

## 三、定缺与胡牌花色限制

换牌结束后，每人从万、条、筒中选择一门作为本局定缺花色，并记录各家的选择。

- 对局中不可更改定缺；摸到定缺花色的牌一定要打出。
- 手中还有定缺牌时，必须优先打出定缺牌；之后摸到定缺牌，仍按此要求处理。
- 胡牌时，暗手与碰杠副露合计不得含定缺花色，最多包含两门花色；清一色可以胡。
- 定缺花色不能碰、明杠、补杠或暗杠，也不能自摸胡或点炮胡。按2026-10-20用户确认，仍持有定缺牌时，可以碰、明杠、补杠或暗杠其他花色；之后出牌仍须优先打定缺牌。

“最多两门花色”与“不得含定缺花色”分别检查；只剩两门但仍有定缺牌时，仍不能胡。

## 四、摸打、碰杠与轮转

庄家先出牌，其他未胡玩家依逆时针轮转。已胡玩家跳过。

| 操作 | 手牌变化与后续动作 |
| --- | --- |
| 普通摸打 | 摸一张；若不胡牌，打出一张 |
| 碰牌 | 用暗手中的两张相同牌碰他人弃牌；不再摸牌，直接出牌 |
| 直杠 | 用暗手中的三张相同牌杠他人弃牌；补牌后，若不胡则出牌 |
| 补杠 | 将已经碰出的刻子加上自己摸到的第四张；先处理抢杠响应，再完成杠和补牌 |
| 暗杠 | 将暗手中的四张相同牌声明为杠；补牌后，若不胡则出牌 |

杠后从牌墙尾部补一张牌（岭上牌），不从正常摸牌位置顺补。按本项目2026-10-19确认，采用腾讯TMT及主流线上平台的尾部补牌版本；《四川麻将竞赛规则》T_TFMJ 01—2024另列“顺杠”（抓牌墙前面第一张）版本，本项目不采用。按本项目2026-10-13的最新约定，碰牌、直杠和补杠全部展示牌面；暗杠四张中只亮一张，另外三张牌背朝上。其他三家未碰杠的暗手平放、牌背朝上，自己的暗手显示牌面。此项覆盖百科所列的暗杠全部亮出方式。

碰杠后由操作玩家继续行动。按项目2026-10-13用户确认，胡牌响应结束后，从逆时针方向最后一位胡牌者的下一位未胡玩家开始摸打；已胡玩家全部跳过。一炮多响按点炮者起沿逆时针的座次确定“最后一位”，不按录入先后排序。按2026-10-20用户确认，胡牌优先于碰牌和杠牌；有胡牌响应时先处理所有合法胡家，该张牌不再用于碰杠。可以主动放弃自己的胡牌选择碰杠，但须记录过手胡。牌墙无牌可补时，任何类型的杠都不允许声明。

## 五、刮风下雨：杠分

每个成功杠单独记录收支，终局汇总；补杠被抢时，该次杠不成立，不计杠分。

下表的“倍”均指底分倍数，不是第七节的牌型番数。

| 类型 | 说明 | 收入 |
| --- | --- | --- |
| 明杠／直杠 | 暗手有三张相同牌，杠他人打出的第四张 | 引杠者支付2倍底分；其他玩家不支付 |
| 贴杠／补杠／弯杠 | 已碰出刻子，自己摸到第四张后补杠 | 其他每位未胡玩家各支付1倍底分 |
| 暗杠 | 暗手中的四张相同牌声明为杠 | 其他每位未胡玩家各支付2倍底分 |

直杠由原文1倍改为百科“麻将游戏”中的2倍。已胡玩家不参与此后新发生的杠分。

按2026-10-20用户确认，补杠可以延迟声明，成功补杠依然计杠分，不要求在首次摸到第四张时立即声明。

只有流局且杠牌者未听牌时，按原约定退还其所得杠分。三家已胡后的正常结束不触发查叫退税。

## 六、胡牌基本条件

必须同时满足花色限制与牌型条件：

1. 暗手与副露合计无定缺牌，最多两门花色。
2. 普通胡牌由四组面子加一对将组成；面子可以是顺子、刻子或杠，每个杠计作一组。
3. 七对为另一种允许的结构，要求没有碰杠副露。

按项目2026-10-14用户确认，庄家起手14张合法成胡时，可在首次出牌前直接记录天胡，无需再摸一张牌。天胡为32倍。

**地胡**：按用户2026-10-19补充，非庄家在第一轮摸牌时胡牌，且胡牌之前场上没有任何玩家碰牌或杠牌，才成立地胡；此前只要有人碰或杠，地胡即不成立。此处不把地胡限定为自摸。地胡为32倍。

胡牌张亮在原“新摸牌”的位置。自己的其余手牌保持亮明，其他三家的未公开手牌继续显示牌背；一炮多响的展示仍引用同一实体弃牌，不重复计数。

听牌指只差一张合法牌即可形成可胡的牌型。实际能否胡还需要检查过手胡等行动限制。

## 七、番型、倍数与不重复计分

### 计分口径与术语

本文采用**平胡1倍记0番、每增加1番倍数×2**的计算口径，即1、2、4、8、16、32、64、128、256、512倍分别对应0至9番。

“金钩钩”又称“金钩钓”，清金钩钩、将金钩钩沿用同一术语。“将牌”指一对相同牌；名称带“将”的牌型依对应定义限制为2、5、8序数牌。胡牌仍须满足定缺、牌数和动作限制。

以下表格的“不另计”表示不重复加算组合已经包含的主牌型。主牌型按表中明确的组合识别；不将清七对再乘一次清一色和七对，不将清碰再乘一次清一色和碰碰胡。未列明的主牌型重合暂按已列最高匹配牌型计算，其他组合是否另加仍见第十二节。

**断幺九、根与胡牌事件是独立加倍项，先应用最新明确排除项，再叠加其他成立的加倍项。龙七对类不再额外算根，连七对不算断幺九。**

**所有七对类番型（包括七对、清七对、将七对、各类龙七对及连七对）和九莲宝灯均不另计门前清。**

### 天地胡、根与胡牌事件

| 条目 | 倍数或加倍 | 定义与处理 |
| --- | --- | --- |
| 天胡 | 32倍 | 庄家发完牌后立即胡牌；项目已允许合法起手14张直接成胡 |
| 地胡 | 32倍 | 非庄家在第一轮摸牌时胡牌；胡牌之前场上必须无人碰牌或杠牌，否则不成立；不限定为自摸 |
| 根 | 每根额外×2 | 暗手中每有1组四张相同且未开杠的牌算1根，胡牌时每根额外×2；龙七对类（含双龙、三龙及清、将组合）、十八罗汉及其清、将组合不额外叠加根；直杠、补杠、暗杠杠出的牌均不计根 |
| 自摸 | ×2 | 自摸胡牌，采用加番版本 |
| 杠上开花 | ×2 | 杠牌后，补张自摸胡牌 |
| 杠上炮 | ×2 | 杠后补牌紧接的出牌被其他玩家胡 |
| 抢杠胡 | ×2 | 胡其他人补杠的那张牌 |
| 海底捞月 | ×2 | 简称“海底”，摸到牌墙中的最后1张牌胡牌 |

### 叠加与封顶状态

- 先选取已列明的匹配主牌型，再乘各独立加倍项。断幺九×2、每根×2、自摸×2、杠上开花×2、天胡×32、地胡×32可与主牌型和其他成立的独立项相乘；龙七对类和十八罗汉类不额外计根，连七对不计断幺九。天胡与地胡互斥。
- 门前清额外×2，但七对类和九莲宝灯不计门前清。暗杠不破坏门前清。
- 自摸与杠上开花同时成立时，两项都计，即合计×4；天胡自摸合计×64，再乘牌型及其他成立的加倍项。
- 杠上炮、抢杠胡和海底捞月按各自真实事件成立时×2；海底炮不额外加倍。听牌展示按普通点炮及普通自摸分别给出倍数，不预加尚未发生的杠上花、天地胡或海底事件；当前实际可胡时才按已发生的事件认证。
- 示例：门前清清一色为4×2＝8倍；再加断幺九为16倍；再自摸为32倍。
- **封顶为512倍**，超过时按512倍计算。

## 八、血战到底与付款对象

一家胡牌后退出本局摸打，未胡玩家继续，直到三家胡牌，或最后一张牌的出牌及响应处理完后仍有至少两家未胡而流局。

- 自摸：由其他仍未胡玩家分别支付。
- 点炮：由点炮者向每位合法胡牌者分别支付，允许一炮多响。
- 已胡玩家不参与后续新发生的胡牌或杠分，但保留已有收支；流局查花猪的付款范围见第十节。
- 已胡暗手沿用原文背面朝上保留的约定；牌局结束时再核验牌型与分数。
- 胡后接续：从本次沿逆时针最后一位胡牌者的下一位未胡玩家开始摸打。自摸时由该胡牌者的下一位未胡玩家接续；一炮多响先录完同一张弃牌的全部胡家，再继续摸打。

本项目选择百科“游戏规则”中引杠后杠上花按自摸付款的版本，即仍未胡的其他玩家付款；不采用引杠者承包版本。

## 九、过手胡与特殊事件

### 过手胡

按百科“游戏规则”，放弃某一张弃牌的胡牌后，在自己下一次摸牌前，不能胡其他玩家再次打出的同一种牌；其他可胡牌面仍可胡。

这是按牌面限制的版本，不套用“所有待牌均禁胡”。按2026-10-20用户确认：碰牌、杠牌本身不解除过手胡；放弃合法自摸也触发该牌面的过手胡。普通摸牌解除此前限制，杠后补牌不因“碰杠”自动解除。

例外：杠牌后若合法胡牌的番数高于此前放弃同一牌面时的番数，可以立即胡牌。须记录放弃时的认证番数和当时杠组数，并用当前完整牌型及真实事件比较；仍须有合法胡牌张和合法胡牌结构，不能只因声明杠就直接记胡。比较加番后的番数，512倍封顶只限制实际付款倍数。

### 特殊事件

| 事件 | 定义与处理 |
| --- | --- |
| 抢杠胡 | 他人补杠时胡其第四张牌；补杠取消，原碰保留，该次杠分无效，补杠者按点炮付款；不允许抢暗杠 |
| 杠上开花 | 杠后补摸的一张牌自摸胡牌，额外×2，并同时计自摸×2 |
| 杠上炮 | 杠后补牌紧接的出牌被其他玩家胡，×2 |
| 呼叫转移 | 杠上炮时将本次杠所赢分数转给胡牌玩家；若连续杠，则本轮连续杠的全部杠收入均转移；**杠上炮导致一炮多响时，不触发呼叫转移** |
| 海底捞月 | 实际摸到牌墙中的最后1张牌并自摸胡牌才成立，额外×2；随后弃牌被胡属于海底炮，不额外加倍 |

按2026-10-20用户确认，退税只退当前仍由该玩家保留的杠牌收入，已呼叫转移出去的杠钱不再重复退税。连续杠链从一次杠开始，经补牌后再次杠可延续，打出牌后结束。

最后四张是否强制胡牌：本文暂采用百科“游戏规则”中的有合法胡牌机会必须胡的版本。条目同时列有可以不胡及定缺玩法可不胡的说明，因此此项是明确选择的草案配置，不是统一川麻规则。

## 十、流局：查花猪、查大叫与退税

只在牌墙耗尽且仍有至少两家未胡时执行。三家已胡后的正常结束不执行。

### 查花猪

对局结束时，**手牌有定缺花色牌的玩家为花猪**。完整局面检查计入暗手与副露。

按2026-10-20用户确认，每名花猪固定赔给其余三家各64倍底分，包含已胡玩家和其他花猪，不再与听牌最大倍数取大。多名花猪各自向其余三家付款，相互应付可在汇总时抵销。花猪不再参加查大叫赔付。

持有定缺牌时，即使只剩两门花色，也不能胡牌、不能算合法听牌，并判为花猪。

### 查大叫

对局结束时，非花猪且未听牌玩家赔给听牌但未胡牌玩家最大可能倍数，**不包含自摸倍数**。采用“赔大”方式，按相应主牌型、门前清、断幺九、根与底分计算；花猪只按查花猪赔付。

本文采用百科所列“死叫算叫、保留杠收入”版本：即使待牌已全部可见，只要牌型仍满足听牌结构，仍作有叫处理。实际可进张数量为零，应与牌型听牌状态分别记录。

查叫只比较补入各待牌后的牌型倍数，不计自摸、杠上花、杠上炮、抢杠胡、天地胡、海底捞月等未真实发生的胡牌事件。流局未听牌不能因假设摸到最后一张而加算海底捞月。

### 退税

对局结束时，未听牌玩家退回当前仍保留的全部杠牌所得，已呼叫转移出去的部分不再重复退还。结合本节的牌墙耗尽结算场景，按原付款人逐笔冲销；不因三家已胡正常结束而另行启动本节流局结算。

花猪持有定缺牌，不能构成合法听牌，按同一退税规则退回目前仍保留的杠牌所得。转移收入与原杠收入使用同一笔杠钱的归属记录，防止同一份收入被转移或退还两次。

## 十一、结算与记录

底分使用一个统一的数值单位，胡牌、杠分和赔付均换算为分数；具体底分可按对局设置。

1. 对局中分别记录成功杠、胡牌和呼叫转移的收支。
2. 流局时记录各家花猪、听牌与已胡状态，按第十节计算赔付与应退杠分；花猪赔三家各64倍，不再赔查大叫。
3. 终局汇总已有收入、支出和冲销记录；已记录的胡牌或杠分不再重复收取。
4. 每家最终净得分为收入减支出；没有外部扣费的四人对局，四家净得分之和应为零。
