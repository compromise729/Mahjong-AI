# 四川麻将血战到底规则

主要依据：[百度百科《四川麻将》](https://baike.baidu.com/item/%E5%9B%9B%E5%B7%9D%E9%BA%BB%E5%B0%86/1287910)。整理日期：2026-10-13。

本文优先采用条目的“游戏规则”，参考“游戏术语”和“麻将游戏”补充流程。条目包含地方差异，本文会明确当前采用的版本。原项目的换三张、番型倍数与512倍封顶继续保留，不能视为全部照搬百科。

**暂缓事项：组合牌型与根的重复计分、叠加关系暂不补充。第七节保留原倍数和叠加文字，只修正牌型定义；这部分尚不能作为完整、无歧义的计分规范。**

## 一、牌张与人数

- 4人参与，使用万、条、筒三门，共108张。
- 每门从1至9，每种牌各4张，共36张。
- 不使用风牌、箭牌和花牌。
- 允许碰、杠、胡，不允许吃牌。

## 二、庄家、发牌与换三张

### 庄家

首局由系统随机确定，实体牌局可通过掷骰确定。后续按百科“游戏术语”的版本，由上一局最先胡牌者坐庄；若首次胡牌事件为一炮多响，则由点炮者坐庄。流局后的坐庄方式暂待确认，不与条目另列的“血战每局投骰”版本混用。

### 发牌与行动方向

本项目沿用原定的逆时针玩家轮转。玩家摸打的顺序与牌墙取牌方向分别记录，不再表述为“玩家顺时针摸牌、逆时针出牌”。

1. 实体牌局由庄家掷两枚骰子确定开牌位置；系统牌局记录洗牌结果及起始位置。
2. 从庄家开始，四家每轮依次各取4张，重复3轮，每家得到12张。
3. 各家再补足手牌：庄家14张、其他三家各13张。
4. 完成换三张和定缺后，由庄家先打出一张牌。

### 换三张：项目保留约定

每人提交3张同花色手牌，四家全部提交后，系统统一确定顺时针、逆时针或对家交换。交换完成后再定缺。

该流程沿用项目原有范围，不是所引百科基础规则中已完整规定的步骤。交换方向的随机方法和实体发牌细节可后续单独规定。

## 三、定缺与胡牌花色限制

换牌结束后，每人从万、条、筒中选择一门作为本局定缺花色，并记录各家的选择。

- 手中还有定缺牌时，必须优先打出定缺牌；之后摸到定缺牌，仍按此要求处理。
- 胡牌时，暗手与碰杠副露合计不得含定缺花色，最多包含两门花色；清一色可以胡。
- 按项目2026-10-13用户确认，定缺花色不能碰、明杠、补杠或暗杠，也不能自摸胡或点炮胡。持有定缺牌时是否允许碰杠非定缺牌，仍列入待确认项。

“最多两门花色”与“不得含定缺花色”分别检查；只剩两门但仍有定缺牌时，仍不能胡。

## 四、摸打、碰杠与轮转

庄家先出牌，其他未胡玩家依逆时针轮转。已胡玩家跳过。

| 操作 | 手牌变化与后续动作 |
| --- | --- |
| 普通摸打 | 摸一张；若不胡牌，打出一张 |
| 碰牌 | 用暗手中的两张相同牌碰他人弃牌；不再摸牌，直接出牌 |
| 直杠 | 用暗手中的三张相同牌杠他人弃牌；补牌后，若不胡则出牌 |
| 补杠 | 将已经碰出的刻子加上自己摸到的第四张；先处理抢杠响应，再完成杠和补牌 |
| 暗杠 | 将暗手中的四张相同牌声明为杠；补牌后，若不胡则出牌 |

杠后从正常摸牌位置补下一张。按本项目2026-10-13的最新约定，碰牌、直杠和补杠全部展示牌面；暗杠四张中只亮一张，另外三张牌背朝上。其他三家未碰杠的暗手平放、牌背朝上，自己的暗手显示牌面。此项覆盖百科所列的暗杠全部亮出方式。

碰杠后由操作玩家继续行动。按项目2026-10-13用户确认，胡牌响应结束后，从逆时针方向最后一位胡牌者的下一位未胡玩家开始摸打；已胡玩家全部跳过。一炮多响按点炮者起沿逆时针的座次确定“最后一位”，不按录入先后排序。胡与碰杠的响应优先级仍列入待确认项。

## 五、刮风下雨：杠分

每个成功杠单独记录收支，终局汇总；补杠被抢时，该次杠不成立，不计杠分。

下表的“倍”均指底分倍数，不是第七节的牌型番数。

| 类型 | 说明 | 收入 |
| --- | --- | --- |
| 明杠／直杠 | 暗手有三张相同牌，杠他人打出的第四张 | 引杠者支付2倍底分；其他玩家不支付 |
| 贴杠／补杠／弯杠 | 已碰出刻子，自己摸到第四张后补杠 | 其他每位未胡玩家各支付1倍底分 |
| 暗杠 | 暗手中的四张相同牌声明为杠 | 其他每位未胡玩家各支付2倍底分 |

直杠由原文1倍改为百科“麻将游戏”中的2倍。已胡玩家不参与此后新发生的杠分。

条目“术语番数”另列弯杠必须在摸到第四张时立即声明才有杠分的版本；本项目采用与否待确认。

只有流局且杠牌者未听牌时，按原约定退还其所得杠分。三家已胡后的正常结束不触发查叫退税。

## 六、胡牌基本条件

必须同时满足花色限制与牌型条件：

1. 暗手与副露合计无定缺牌，最多两门花色。
2. 普通胡牌由四组面子加一对将组成；面子可以是顺子、刻子或杠，每个杠计作一组。
3. 七对为另一种允许的结构，要求没有碰杠副露。

按项目2026-10-14用户确认，庄家起手14张合法成胡时，可在首次出牌前直接记录天胡，无需再摸一张牌。非庄家第一轮摸牌成胡时，也可正常记录自摸。

胡牌张亮在原“新摸牌”的位置。自己的其余手牌保持亮明，其他三家的未公开手牌继续显示牌背；一炮多响的展示仍引用同一实体弃牌，不重复计数。

听牌指只差一张合法牌即可形成可胡的牌型。实际能否胡还需要检查过手胡等行动限制。

## 七、番型与倍数：项目保留约定

每加1番，倍数×2。本文使用相对基础倍数，避免与百科“1番对应1倍”的起始编号混淆。

| 番型 | 倍数 | 说明 |
| --- | --- | --- |
| **平胡** | 1倍 | 基础胡牌 |
| **碰碰胡** | 2倍 | 四组刻子或杠加一对将，不含顺子 |
| **清一色** | **4倍** | 暗手与副露全部同一花色 |
| **七对** | **4倍** | 七个对子，无碰杠副露 |
| **金钩钓** | **4倍** | 四组面子均已碰杠，听牌时暗手仅一张，胡后形成一对将 |
| **清碰** | 8倍 | 清一色+碰碰胡 |
| **龙七对** | **16倍** | 七对中含一个“根”（四张相同），不再另算根 |
| **清七对** | 16倍 | 清一色的七对 |
| **清龙七对** | **32倍** | 清一色的龙七对 |
| **十八罗汉** | **64倍** | 四个杠牌加一对将 |

**叠加规则**：
- **根**：每有1个四张相同的牌（无论是否杠出），在基础倍数上 **×2**。
- **自摸、杠上花、杠上炮、抢杠**：各**加1番**（即**×2**），与基础番型和根**相乘叠加**。
- **封顶**：**512倍**。超过按512倍计算。

以上叠加文字本轮原样保留，组合牌型重复计分问题继续暂缓。龙七对16倍和512倍封顶等为项目保留值，不宣称与百科全部一致；本轮不增加百科另列的其他牌型或自摸加底版本。

## 八、血战到底与付款对象

一家胡牌后退出本局摸打，未胡玩家继续，直到三家胡牌，或最后一张牌的出牌及响应处理完后仍有至少两家未胡而流局。

- 自摸：由其他仍未胡玩家分别支付。
- 点炮：由点炮者向每位合法胡牌者分别支付，允许一炮多响。
- 已胡玩家不参与后续新发生的胡牌或杠分，但保留已有收支；流局查花猪时仍可作为非花猪收款人。
- 已胡暗手沿用原文背面朝上保留的约定；牌局结束时再核验牌型与分数。
- 胡后接续：从本次沿逆时针最后一位胡牌者的下一位未胡玩家开始摸打。自摸时由该胡牌者的下一位未胡玩家接续；一炮多响先录完同一张弃牌的全部胡家，再继续摸打。

本项目选择百科“游戏规则”中引杠后杠上花按自摸付款的版本，即仍未胡的其他玩家付款；不采用引杠者承包版本。

## 九、过手胡与特殊事件

### 过手胡

按百科“游戏规则”，放弃某一张弃牌的胡牌后，在自己下一次摸牌前，不能胡其他玩家再次打出的同一种牌；其他可胡牌面仍可胡。

这是按牌面限制的版本，不额外套用其他平台的“所有待牌均禁胡”或“升番解除”规则。碰杠是否解除限制、弃自摸是否触发限制，条目未明确，暂待确认。

### 特殊事件

| 事件 | 定义与处理 |
| --- | --- |
| 抢杠胡 | 他人补杠时胡其第四张牌；补杠取消，原碰保留，该次杠分无效，补杠者按点炮付款；不允许抢暗杠 |
| 杠上开花 | 杠后补摸的一张牌构成胡牌；原文额外2倍保留 |
| 杠上炮 | 杠后补牌紧接的出牌被其他玩家胡；原文额外2倍保留 |
| 呼叫转移 | 杠上炮时转移刚刚这次杠的收入，不是本局全部历史杠收入；一炮多响时每位胡牌者分别获得一份等额转移 |
| 海底 | 最后一张牌形成自摸或其后弃牌形成点炮；原文额外2倍保留，具体事件叠加继续暂缓 |

连续杠对应的转移范围、转移后流局退税如何处理，条目没有充分定义，暂待确认。

最后四张是否强制胡牌：本文暂采用百科“游戏规则”中的有合法胡牌机会必须胡的版本。条目同时列有可以不胡及定缺玩法可不胡的说明，因此此项是明确选择的草案配置，不是统一川麻规则。

## 十、流局：查花猪、查大叫与退税

只在牌墙耗尽且仍有至少两家未胡时执行。三家已胡后的正常结束不执行。

### 查花猪

沿用原文及百科“麻将游戏”的三门判定：未胡玩家的暗手与副露合计仍有万、条、筒三门，则为花猪。

每位花猪向每位非花猪支付16倍底分；非花猪包括已胡玩家。花猪不再参加查大叫赔付。

持有定缺牌但只有两门花色时，不能胡牌，也不能算合法听牌；依当前三门花猪判定，按未听牌处理。此处不切换为残留定缺牌即花猪的其他版本。

### 查大叫

仅在未胡且非花猪玩家之间进行。未听牌者分别赔付每位听牌者可形成的最大胡牌倍数，采用百科所列“赔大”版本。

本文采用百科所列“死叫算叫、保留杠收入”版本：即使待牌已全部可见，只要牌型仍满足听牌结构，仍作有叫处理。实际可进张数量为零，应与牌型听牌状态分别记录。

查叫是否计自摸、海底等事件加番，以及与保留计分体系的衔接，暂待确认。

### 退税

沿用原文：流局时未听牌玩家所得杠分全部退回；先核对原付款人，再冲销对应收支。花猪退税的适用范围和已经呼叫转移的杠钱如何冲销，暂待确认。

## 十一、结算与记录

底分使用一个统一的数值单位，胡牌、杠分和赔付均换算为分数；具体底分可按对局设置。

1. 对局中分别记录成功杠、胡牌和呼叫转移的收支。
2. 流局时先判断花猪，再判断其他未胡玩家是否听牌，计算赔付与应退杠分。
3. 终局汇总已有收入、支出和冲销记录；已记录的胡牌或杠分不再重复收取。
4. 每家最终净得分为收入减支出；没有外部扣费的四人对局，四家净得分之和应为零。

## 十二、仍需确定的边界

| 项目 | 当前状态 |

| 组合牌型、根与事件叠加 | 按要求暂不补充；保留第七节 |
| 流局后的下一局庄家 | 条目存在不同坐庄版本，待明确 |
| 仍持有定缺牌时碰杠非定缺牌 | 待明确合法动作范围；定缺牌本身禁止碰杠胡已由用户确认 |
| 胡与碰杠的响应优先级 | 待明确，不能仅凭文字顺序实现；胡后接续轮转已按用户约定明确 |
| 弯杠延迟声明是否有杠分 | 待确认是否采用即时声明版本 |
| 过手胡的碰杠解除与弃自摸 | 条目未明确 |
| 最后一张时无牌可补的杠操作 | 待明确，不能执行缺少补牌的完整杠流程 |
| 连杠呼叫转移与退税 | 待明确账目范围及冲销方式 |
| 花猪退税与查叫计分事件 | 待明确，与第七节衔接 |
