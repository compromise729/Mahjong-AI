# 原创四川麻将牌面

按用户2026-10-13最新要求重新绘制，参考其提供的传统麻将风格，不使用原照片作为成品，也不采用生成稿里的误绘牌面。

- `wan-1`至`wan-9`：真实楷体数字与传统“萬”字；中文转为固定轮廓，素材显示不依赖字体替换。
- `tiao-1`至`tiao-9`：一条为鸟形，其他牌面按固定竹节数量与排列绘制。
- `tong-1`至`tong-9`：逐枚绘制圆环；一筒为单枚花纹圆环。
- `back.svg`及`back.png`：统一牌背。
- `manifest.json`：27种牌的ID、中文名称、花色、数字与SVG文件映射。
- `tile-catalog.png`：1780×1080完整校对图。
- `tile-revisions.png`：八条、七条、九条及五、六、七、八筒的放大校对图，附加粗后的其他条牌。
- `tile-corrections-v3.png`：最新八条、七条、五筒、六筒的独立放大校对图。

最新修订：六条为上下两行、每行三根绿色竹节（2行×3列）；八条以八根等长等粗竹节对称拼接；七条下方为三组竖向绿色双竹；九条中间一列为红色；条牌加粗；五筒上下两排稍微拉开；六筒四个红圈整体下移，七、八筒维持紧凑排列。

单张SVG为160×216，PNG为320×432。条筒数量与万牌数字均有结构检查；生成工具位于项目根目录`tools`。

本目录只包含牌面素材及校对图，尚不代表交互页面已经实现。界面中文应使用人工编写的字符串，与素材名称一致。
