# 四川麻将桌交互页面设计规格

状态：用户已确认并实现前端；最终浏览器验收记录见 `ui/design-qa.md`。日期：2026-10-13。

## 后续用户确认的修改（2026-10-13）

以下内容覆盖初始规格中的对应行为：

- 别家摸牌记为未知牌，不选择或泄露牌面；暗手之外单独显示一张间隔牌背，确认出牌后移除。碰牌后有待出的额外暗手张数，杠后须补摸。
- 新增自摸与点炮胡牌；自己校验定缺与结构，别家的未知暗手由用户按现场结果录入。胡牌者保留牌背并退出全部后续动作，三家胡牌后本局结束，撤销恢复。
- 按用户最新明确的血战规则，从本次沿逆时针最后一位胡牌者的下一位未胡玩家接续。多响按点炮者起的座次确定最后一位，与记录先后无关；当前弃牌响应结束前可逐家记录多响。用于胡牌的具体弃牌不再允许碰杠，已知数量只计一次。

- 他家未碰杠时完整显示13张牌背，碰杠后按实际暗手数展示。上下家的牌背尺寸须适应桌面高度，不能裁掉最后两张，并显示实际暗手张数。
- 成功记录出牌后，按上家→我→下家→对家→上家自动选择下一家；手动选择自己默认“自己摸牌”，其他人默认“出牌”。自己摸牌后自动切到自己的出牌；碰杠后保留操作玩家，杠后自己的下一步为补摸。失败不前进，撤销恢复对应操作玩家。
- 碰杠菜单只显示实际动作，移除“碰杠”占位项。
- 自己出牌后将剩余手牌按万、条、筒及1—9排序，新摸牌继续单独展示。
- 新增实时规则听牌分析，采用用户给出的递归拆面子思路，补足定缺、最多两门、正确总张数、副露以及七对结构判断。显示待牌及未见张数；14张时可预览打出所选牌后的待牌。未见张数不等于牌墙剩余量，听牌分析不冒充AI推荐。

下面保留初始设计规格作为历史依据；冲突时以上后续用户要求优先。

## 目标与本次范围

为手动记录四川麻将牌局制作可操作的桌面网页。用户能直观看到自己的牌、各家弃牌及碰杠，选择谁打了什么牌或自己摸到了什么牌，并撤销录错的事件。

视觉采用用户选择的第二种方案：暖白页头与操作区、浅青绿牌桌、实物白色麻将牌。桌面上方为对家，左侧为上家，右侧为下家，下方为自己。牌桌是主要区域，事件选择器位于下方。

本次交付是前端交互原型。AI分析模块保留入口与空状态，明确显示尚未接入；不输出编造的推荐、概率或分数。计分模型、识图、训练、后端和持久化不在本次范围内。

## 视觉依据与优先级

1. 用户最新要求：牌面准确；其他三家暗手平放、牌背朝上；碰杠公开；暗杠只亮一张。
2. 用户提供的实物图：`assets/mahjong-tile-reference.png`，800×800，仅参考传统牌面风格、数量与排列，不作为成品素材，不裁切或嵌入页面。
3. 用户选择的第二张稿：`assets/warm-table-selected.png`，作为整体布局、颜色与层级依据。
4. 修正版：`assets/warm-table-layout-revision.png`，仅用于说明副露分组和底部录入区域。生成稿仍有牌面误绘及中文字形错误，不作为牌面或文字素材依据。
5. 原创牌面素材位于项目根目录`assets/tiles`，以`tile-catalog.png`逐张校对；SVG为绘制源，PNG为高清预览。最新要求为重新绘制，禁止使用用户原照片作为成品牌面。

桌面主视口按1440×1024设计，适配1280宽度。窄屏允许操作区换行及手牌区域横向滚动；任何核心操作不得被截断。不是另做一套手机应用。

## 牌面与牌背素材

- 只使用万、条、筒，共27种牌，每张用固定ID关联花色、数字、中文名称及独立SVG素材，清单为`assets/tiles/manifest.json`。
- 按用户明确要求原创绘制高清矢量牌面，不裁切照片，不使用生成稿里误绘的牌面，不用生成式文字处理中文。此要求覆盖设计技能默认优先使用生成图资产的流程。
- 万牌使用真实楷体数字及传统“萬”字，固定为矢量轮廓，避免缺字、字体替换或把二画成错误字符；界面名称使用规范简体“一万”至“九万”。
- 一条绘制鸟形；二至九条使用加粗竹节与端头，五条中间一根为红色；七条上方一根红色，下方六根绿色竹节组成三组竖向双竹，不能排成三行两列；九条三行三列且中间一列为红色。
- 八条参考`assets/eight-bamboo-style-reference.png`的传统拼接布局，以八根同长、同粗、有竹节的独立竹子对称拼接；每组四根，上下两组镜像排列，不画成连续软曲线。当前竹节长度为52、宽度为16个矢量单位，左右及上下位置严格对称。
- 一筒绘制一枚花纹圆环；二至九筒逐个绘制独立圆环，三筒斜排、四筒四角、五筒四角加中心，六至九筒按传统排列逐枚核对。二筒、六筒、七筒、八筒保留较紧凑的排列；五筒按最新要求将上下两排稍微拉开，中心红圈不变；六筒的四个红圈整体下移8个矢量单位，顶部两个绿圈不变。
- 所有牌共用统一的160×216矢量尺寸、暖白底与颜色；同时提供320×432 PNG。牌背单独绘制，未公开牌只使用牌背素材。
- 同一固定映射用于自己的牌、弃牌、副露、选择器及事件预览，确保文字名称和实际牌面一致。
- 页面标题、按钮、说明、事件名称以人工编写的真实中文字符串排版，使用中文字体；不从生成图中裁取文字，不添加拼接的假字。

## 页面结构

页头显示“川麻 · 决策助手”、手动记录标识与规则入口。规则通过同页抽屉阅读，不新增站外页面。

牌桌中分开显示每家的暗手、弃牌、碰杠副露、座位与定缺。其他三家暗手只有牌背，不使用假设的隐藏牌面。自己的手牌面向用户，新摸牌与原手牌之间保留间隔。

下方白色操作区包含座位选择、事件选择、三行选牌器（每行一个花色、数字1—9）、已选牌预览、确认记录、撤销、手牌设置和近期事件。选中与悬停状态清楚区分，按钮有键盘焦点与中文可访问名称。

## 核心交互

### 初始化手牌

“手牌设置”打开同页面板，可逐张加入、移除自己的起始牌，并选择自己是否为庄家。确认时要求庄家14张、闲家13张；重复牌最多4张。可设置各家的公开定缺信息。

提供一组清楚标记的演示牌局用于初看；用户可进入手牌设置建立自己的牌局。演示数据需先检查每种牌总量及副露张数。

### 记录摸牌与出牌

- 自己摸牌：选择牌面、预览、确认；加入自己手牌并标出新摸牌。没有完成初始化或手牌状态不允许摸牌时，说明原因。
- 自己出牌：可点选手牌或选择器，确认后移除手牌中的一张，并加入自己的弃牌区；不允许打出手上不存在的牌。
- 其他玩家出牌：选择座位与牌面，确认后加入该家弃牌区。不会要求录入其他玩家摸到的具体牌面。
- 切换座位与事件时更新预览；“自己摸牌”仅对自己开放。
- 每次提交只生成一条事件，失败不改变牌局。确认后保留座位以便连续录入，清除本次牌选择，避免误重复提交。

### 记录碰杠

“碰杠”菜单提供碰、直杠、补杠、暗杠。碰和直杠需要选择来源玩家及尚未被使用的对应弃牌；将该弃牌转入副露，不能重复计入可见牌数量。

- 碰：三张同牌全部展示。
- 直杠、补杠：四张同牌全部展示。补杠升级已有碰组。
- 暗杠：一张展示牌面，三张展示牌背；记录的牌种与四张数量保留于牌局状态，不额外向用户显示其他三张牌面。
- 自己碰杠需校验并移除相应暗手牌。其他三家的暗手只维护张数，不虚构牌面。
- 其他三家碰杠后的暗手张数按副露数量调整；普通出牌记录不误把暗手永久减少一张。

原型不自动执行完整轮转、抢杠裁决或计分。已确认的记录直接更新展示；规则中尚未确定的限制不能偷偷采用某个平台的实现。

### 撤销与规则

撤销恢复上一条记录前的完整状态，包括自己的牌、弃牌、副露、对手暗手张数、当前事件列表及新摸牌标记。无事件时禁用撤销。

规则抽屉展示当前规则摘要和文档的未确定项，突出最新暗杠展示约定。分析区默认提示“决策分析尚未接入 · 当前可记录与查看牌局”。

## 状态与组件设计

采用本地前端状态、事件历史和撤销快照；一套牌面映射驱动所有区域。每家保留暗手或暗手张数、定缺、弃牌与副露；副露记录类型、牌种、来源与显示方式。

组件划分为牌图、玩家区域、牌桌、手牌区、事件录入器、手牌设置、规则抽屉和近期记录。显示组件只消费状态，事件更新集中处理，避免同一牌被重复使用或不同区域各自维护一份牌局。

使用Product Design的网页原型模板，在独立的`ui`目录开发。实际依赖、文件清单与执行顺序在规格确认后的实施计划中列明。

## 验收标准

1. 27种原创牌面逐张核对，名称、花色、数字和竹节或筒子数量及排列一致；不嵌入原照片，没有风牌、箭牌、花牌、乱码、假字或错误条筒数量。
2. 三家暗手平放、牌背朝上；碰组为3张同牌；直杠、补杠为4张同牌；暗杠为1张正面、3张背面。
3. 选择自己摸牌并确认后，手牌增加且新摸牌分离展示；自己出牌后手牌减少、弃牌增加。
4. 他家出牌、碰、直杠、补杠、暗杠及撤销能够改变并恢复正确的桌面状态。
5. 所有已知牌按真实位置统计：来源弃牌被副露接走后不再重复计算；每种最多4张，暗杠按4张计数；选择器展示不计入牌局。
6. 对手暗手未知牌面不泄漏；实际牌墙剩余量不从未见牌数量直接推断。
7. 核心操作在桌面与窄屏可访问，错误信息明确，重复提交不会生成额外记录。
8. 本地浏览器实际操作上述流程，并核对规则文档；对照所选视觉稿检查布局、字体、色彩与文案。牌面以原创素材清单及校对图验收；生成稿中误绘的牌面和假字必须替换。

验收包含必要的状态转换测试与浏览器操作，不把仅编译成功视为交互完成。页面实现通过视觉QA后才作为可用原型交付。

## 2026-10-13后续交互约定

- 摸牌后锁定该玩家，完成出牌或自摸胡前不能切换别家。碰后出牌、杠后补牌继续保持行动锁，撤销完整恢复。
- 碰、明杠、点炮胡自动带入当前最近弃牌及其来源，取消相应选牌和选来源步骤。自摸为独立动作，自己的自摸使用新摸牌。
- 定缺花色禁止所有碰杠和胡；持有定缺牌时对非定缺牌的碰杠边界仍待明确。
- 当前弃牌至少可胡、碰、明杠一项时才显示响应栏，全部不可用则隐藏。
- 设置起始手牌时选择四家中的庄家，庄家14张、其余13张，从庄家首打开始。右上角显示剩余牌墙：起手55张，普通及杠后摸牌均减1，撤销恢复。
